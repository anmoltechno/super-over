# Super Over

Quick-fire cricket in your browser: swipe to bat, aim to bowl, two overs a side.

**Play: https://anmoltechno.github.io/super-over/**

Also links straight into a mode: [Blitz](https://anmoltechno.github.io/super-over/?play=blitz) · [Super Over](https://anmoltechno.github.io/super-over/?play=superover) ·
[Quick Match](https://anmoltechno.github.io/super-over/?play=quick) · [Nets](https://anmoltechno.github.io/super-over/?play=nets) · [World Tour](https://anmoltechno.github.io/super-over/?play=tour)
